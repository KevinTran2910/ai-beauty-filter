# Build Guide

The iOS app does not build the C++ engine — the engine is **prebuilt** inside
`BeautyFilter.xcframework`. The build only: generates the React Native app, links
the local CocoaPod `BeautyFilterSDK`, compiles the ObjC++ bridge, and packages the
resources.

## Toolchain

| Tool | Version/source | Notes |
|---|---|---|
| macOS + Xcode | required | Needed to compile iOS and run on device |
| Node.js | ≥ 18 | React Native CLI |
| React Native CLI | `@react-native-community/cli@latest` | `bootstrap.sh` calls `init` |
| CocoaPods | recent | Links the local pod, copies resources |
| C++ standard | C++17 | `CLANG_CXX_LANGUAGE_STANDARD` in the podspec |
| C++ library | libc++ | `CLANG_CXX_LIBRARY` |
| iOS deployment target | `15.1` | `s.platform = :ios, '15.1'` |
| Architectures | `arm64` (device), `arm64-simulator` | the two slices in the xcframework |

## Dependencies

JS/React Native (installed by `bootstrap.sh`):

```text
@react-native-community/slider
react-native-image-picker
```

Native (via `BeautyFilterSDK.podspec`):

- `BeautyFilter.xcframework` — prebuilt GPUPixel engine (two slices: `ios-arm64`,
  `ios-arm64-simulator`).
- `MNN.framework` + `libmars-face-kit.a` — face detection, **device slice only**.
- `React-Core` — `RCTViewManager`, `RCTBridgeModule` headers.
- System frameworks: `UIKit`, `AVFoundation`, `CoreVideo`, `CoreMedia`,
  `CoreGraphics`, `QuartzCore`, `OpenGLES`, `Accelerate`. Device builds also link
  `CoreML` and `Metal`.

## Source Layout

```text
ios/
├── bootstrap.sh                 # generates + updates the RN app
├── BeautyFilterSDK.podspec      # local CocoaPod
├── native-bridge/               # ObjC++ bridge (.h/.mm)
├── prebuilt-sdk/ios/            # engine + framework + res + models
│   ├── BeautyFilter.xcframework
│   ├── MNN.framework
│   ├── libmars-face-kit.a
│   ├── include/gpupixel/        # headers
│   ├── res/                     # LUTs + makeup texture
│   └── models/                  # face_det / face_align
├── app-template/                # App.tsx + src/index.ts (overlay)
└── BeautyFilterDemo/            # RN app generated by bootstrap (reproducible)
```

`BeautyFilterDemo/` is generated and is **not** the canonical source — it can be
recreated at any time with `bootstrap.sh`.

## Bootstrap

```bash
cd ios
./bootstrap.sh
```

`bootstrap.sh` does the following:

1. Checks for macOS + `node`/`npx`/`pod` and the existence of
   `BeautyFilter.xcframework`.
2. `npx @react-native-community/cli init BeautyFilterDemo --skip-install` (skipped
   if it already exists).
3. `npm install` + installs `@react-native-community/slider` and
   `react-native-image-picker`.
4. Overlays `app-template/App.tsx` → `BeautyFilterDemo/App.tsx` and
   `app-template/src/index.ts` → `BeautyFilterDemo/src/index.ts`.
5. Inserts `pod 'BeautyFilterSDK', :path => '../..'` into
   `BeautyFilterDemo/ios/Podfile`.
6. Adds `NSPhotoLibraryUsageDescription` + `NSCameraUsageDescription` to
   `Info.plist` (via PlistBuddy).
7. `RCT_NEW_ARCH_ENABLED=0 pod install`.

> The demo **disables New Architecture** (`RCT_NEW_ARCH_ENABLED=0`) so that the
> prop-driven bridge and `requireNativeComponent` run reliably.

## Podspec Configuration

`BeautyFilterSDK.podspec` packages four things:

```ruby
s.source_files        = 'native-bridge/**/*.{h,mm}'                  # 1. ObjC++ bridge
s.vendored_frameworks = 'prebuilt-sdk/ios/BeautyFilter.xcframework'  # 2. engine
s.resources           = ['prebuilt-sdk/ios/res', 'prebuilt-sdk/ios/models'] # 3. resources
s.dependency 'React-Core'
```

### Device/simulator slice split

The most important part — the face detector is enabled only on device:

```ruby
s.pod_target_xcconfig = {
  'CLANG_CXX_LANGUAGE_STANDARD' => 'c++17',
  'CLANG_CXX_LIBRARY'           => 'libc++',
  'HEADER_SEARCH_PATHS'         => '".../prebuilt-sdk/ios/include"',

  # DEVICE slice (iphoneos): enable detector + link MNN/CoreML/Metal/mars
  'GCC_PREPROCESSOR_DEFINITIONS[sdk=iphoneos*]' => '$(inherited) GPUPIXEL_ENABLE_FACE_DETECTOR=1',
  'FRAMEWORK_SEARCH_PATHS[sdk=iphoneos*]'       => '".../prebuilt-sdk/ios"',
  'LIBRARY_SEARCH_PATHS[sdk=iphoneos*]'         => '".../prebuilt-sdk/ios"',
  'OTHER_LDFLAGS[sdk=iphoneos*]'                => '$(inherited) -framework MNN -framework CoreML -framework Metal -l"mars-face-kit"',
  # SIMULATOR slice: no macro defined, no MNN/mars linked
}
```

| Flag | Scope | Meaning |
|---|---|---|
| `GPUPIXEL_ENABLE_FACE_DETECTOR=1` | `iphoneos` | Enables the face-detector `#ifdef` in the bridge |
| `-framework MNN -framework Metal -framework CoreML` | `iphoneos` | Links the MNN backend |
| `-l"mars-face-kit"` | `iphoneos` | Links the landmark static lib |
| (nothing) | simulator | Detector off, smoothing/whitening only |

## Run

### Metro (required for debug builds)

```bash
cd ios/BeautyFilterDemo
npx react-native start
```

### Simulator

```bash
cd ios/BeautyFilterDemo
npx react-native run-ios --simulator "iPhone 17"
```

Testable: app boot, image picker, static-image render, smoothing, whitening, the
slider/wrapper. **Not** testable: camera and landmark-dependent effects.

### Physical iPhone

```bash
open ios/BeautyFilterDemo/ios/BeautyFilterDemo.xcworkspace
```

In Xcode: target `BeautyFilterDemo` → Signing & Capabilities → select Team →
connect an iPhone → Run.

## Permissions and Info.plist

`bootstrap.sh` adds:

```xml
<key>NSPhotoLibraryUsageDescription</key>
<string>The app needs photo-library access to pick an image to beautify.</string>
<key>NSCameraUsageDescription</key>
<string>The app needs the camera for real-time beauty mode.</string>
```

Without these two keys, iOS crashes when opening the picker/camera.

## Troubleshooting

### `Could not connect to localhost:8081` / `No script URL provided`

Metro is not running. `cd ios/BeautyFilterDemo && npx react-native start`, then
reload the app.

### `pod install` fails because CocoaPods is missing

```bash
brew install cocoapods
cd ios && ./bootstrap.sh
```

### Device build fails while linking MNN/mars

Check that these exist:

```text
prebuilt-sdk/ios/MNN.framework
prebuilt-sdk/ios/libmars-face-kit.a
```

If missing, restore the prebuilt SDK package.

### Camera does not appear on the simulator

Expected. `GPUPixelCameraView.startCamera` returns early on the simulator
(`#if TARGET_OS_SIMULATOR`). Use a physical iPhone.

### Face slim / eye enlarge / blush not visible on the simulator

The simulator slice does not define `GPUPIXEL_ENABLE_FACE_DETECTOR` (MNN/mars are
device-only). Test landmark effects on a physical iPhone.

### Black preview / nothing renders

- `SinkView` needs valid bounds — check that the view has a size
  (`!CGRectIsEmpty(self.bounds)`).
- Confirm camera permission is granted.
- Look for the `[GPUPixel]` log tag in the Xcode console.

## Moving to a New Machine

```bash
cd ios && ./bootstrap.sh
```

You do not need to copy `BeautyFilterDemo/node_modules` or `ios/Pods`. You **must
keep** `prebuilt-sdk/ios/` because it contains the binary engine and resources.
