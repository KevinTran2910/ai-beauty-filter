# Beauty Filter SDK — iOS Documentation

This documentation set describes the AI Beauty Filter SDK on **iOS**: the
React Native demo app, the ObjC++ native bridge, the prebuilt GPUPixel engine,
the filter pipeline, and integration options.

The SDK delivers a GPU beauty pipeline (skin smoothing, whitening, face slimming,
eye enlargement, and blush) for both static images and a real-time front camera,
through two React Native components: `GPUPixelImageView` and
`GPUPixelCameraView`.

## Scope

This repository is an iOS-focused React Native demo. The source root contains the
native bridge, the prebuilt SDK, the app template, and the bootstrap script. The
`BeautyFilterDemo/` directory is a React Native app generated by `bootstrap.sh`
and can be recreated when needed.

Demo capabilities:

- Pick an image from the photo library and render it through the beauty pipeline.
- Adjust `smoothing`, `whitening`, `faceSlim`, `eyeEnlarge`, and `blusher`.
- Run real-time camera beauty filtering on a physical iPhone.
- Run simulator builds for filters that do not require face landmarks (smoothing
  and whitening).
