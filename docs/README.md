# Beauty Filter SDK Docs

This documentation set describes the AI Beauty Filter demo system, source-code
layout, usage flow, and future integration options for a more advanced iOS team.

## Suggested Reading Order

1. [SYSTEM_OVERVIEW.md](./SYSTEM_OVERVIEW.md) - high-level architecture, data
   flow, React Native components, CocoaPods integration, native bridge, and
   prebuilt SDK layout.
2. [USAGE_GUIDE.md](./USAGE_GUIDE.md) - bootstrap steps, simulator/device runs,

3. [IOS_INTEGRATION_GUIDE.md](./IOS_INTEGRATION_GUIDE.md) - future integration

## Current Scope

This repository is an iOS-focused React Native demo. The source root contains
the native bridge, prebuilt SDK, app template, and bootstrap script. The
`BeautyFilterDemo/` directory is a React Native app generated by `bootstrap.sh`
and can be recreated when needed.

Demo capabilities:

- Pick an image from the photo library and render it through the beauty pipeline.
- Adjust `smoothing`, `whitening`, `faceSlim`, `eyeEnlarge`, and `blusher`.
- Run real-time camera beauty filtering on a physical iPhone.
- Run simulator builds for filters that do not require face landmarks, such as
  smoothing and whitening.
